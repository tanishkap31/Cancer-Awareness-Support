# 🎗️ Cancer Awareness & Support

> **Together Against Cancer** — spreading hope, knowledge, and strength to people affected by cancer and supporting their families at every step.

## 📌 About the Project

**Cancer Awareness & Support** is a responsive web project created to promote cancer awareness and provide supportive information for people affected by cancer and their families.

The project focuses on:

- 🎗️ Creating awareness about cancer
- 📚 Sharing useful and informative content
- ❤️ Providing emotional support and encouragement
- 🌱 Promoting early awareness and the importance of timely action
- 🤝 Supporting patients, survivors, and their families

## 🌐 Live Demo

👉 **[Visit Cancer Awareness & Support](https://cancerr.netlify.app/)**

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/tanishkap31/Cancer-Awareness-Support.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.

No additional installation or server setup is required for the basic static website.
